## Sobre mim

Atuo como **SysAdmin Sênior**, com experiência prática em infraestrutura corporativa, administração de servidores Windows e Linux, cloud, redes, segurança, monitoramento, automação e troubleshooting de ambientes críticos.

Minha evolução profissional está direcionada para **DevOps, Cloud Engineering e Site Reliability Engineering**, conectando a experiência operacional de infraestrutura com práticas de engenharia, automação, entrega contínua e observabilidade.

Tenho um perfil prático e analítico: gosto de entender como os sistemas funcionam, identificar gargalos, reduzir riscos e criar soluções reproduzíveis.

## Projeto em destaque

### [DevOps SRE Lab](https://github.com/lucasgonella/devops-sre-lab)

Laboratório prático criado para aplicar, de ponta a ponta, conceitos utilizados em ambientes DevOps e SRE.

O projeto já inclui:

- API em Python com FastAPI
- endpoints de health check e readiness
- testes automatizados com Pytest
- imagem Docker versionada
- smoke test do container no CI
- publicação automática no GitHub Container Registry
- definição de execução com Docker Compose
- fluxo de trabalho com branches, Pull Requests e validação automatizada

O roadmap acompanha a evolução para deploy real, observabilidade, banco de dados, infraestrutura como código e Kubernetes.
